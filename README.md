# AIML Session 23 Assignment

## Overview
This repository contains the AIML Session 23 assignment implementing different Machine Learning algorithms. The project covers data preprocessing, model training, prediction, evaluation, and comparison of various algorithms.

## Algorithms Implemented

### 1. Linear Regression
- Used a dataset with a continuous target variable.
- Performed data preprocessing.
- Trained a Linear Regression model.
- Evaluated using R² Score.
- Generated predictions.

### 2. Logistic Regression
- Used a binary classification dataset.
- Applied preprocessing techniques.
- Trained a Logistic Regression model.
- Evaluated using:
  - Confusion Matrix
  - Accuracy
  - Precision
  - Recall
  - F1 Score

### 3. K-Nearest Neighbors (KNN)
- Implemented KNN classification.
- Tested different values of K:
  - K = 3
  - K = 5
  - K = 7
- Compared accuracy and selected the best K value.

### 4. Naive Bayes
- Trained a Naive Bayes classification model.
- Evaluated using:
  - Classification Report
  - Confusion Matrix

### 5. Algorithm Comparison
Compared the performance of:
- Logistic Regression
- K-Nearest Neighbors
- Naive Bayes

Evaluation metrics:
- Accuracy
- Precision
- Recall
- F1 Score
